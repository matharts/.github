<h1 align="center">MathArts</h1>

<p align="center">
  <strong>用象数描述万物，用术法计算万物。</strong>
</p>

<p align="center">
  以现代数学、计算机科学与软件工程，建设中国数术领域的开放计算基础设施、公共规范与应用生态。

## 从这里开始

- 想了解组织边界、治理和项目协作关系：阅读 [`matharts/ecosystem`](https://github.com/matharts/ecosystem)。
- 想使用或参与天文历法基础能力：查看 [`matharts/epheon`](https://github.com/matharts/epheon)。
- 想参与紫微斗数计算基础设施：查看 [`matharts/ziwei`](https://github.com/matharts/ziwei)。
- 想参与通用基础设施建设：查看 [`matharts/matharts`](https://github.com/matharts/matharts)。
- 想使用或维护 MathArts Agent Skills：查看 [`matharts/skills`](https://github.com/matharts/skills)。

## 核心仓库

| 仓库 | 类型 | 当前定位 |
| --- | --- | --- |
| [`ecosystem`](https://github.com/matharts/ecosystem) | Organization | 组织愿景、架构、治理、仓库边界和协作规范的权威来源；当前规范为 Draft、持续演化 |
| [`matharts`](https://github.com/matharts/matharts) | Foundation | MathArts 生态的领域无关基础设施 |
| [`epheon`](https://github.com/matharts/epheon) | Domain | 面向中国历法体系的、标准驱动的天文历法引擎 |
| [`ziwei`](https://github.com/matharts/ziwei) | Domain | 紫微斗数计算、分析与命盘可视化基础设施；仓库当前标记为 Alpha |
| [`skills`](https://github.com/matharts/skills) | Tooling | 可复用 Agent Skills 与能力模块；当前 Skill 主要处于 Experimental 状态 |
| [`.github`](https://github.com/matharts/.github) | Organization | 组织主页、默认社区健康文件、Issue/PR 模板和文档自动化 |

项目成熟度、安装方式和支持范围以各仓库自己的 README、Release 和维护状态为准。本页只提供导航，不复制项目内部事实。

## 参与 MathArts

小型文档修复和范围明确的 Bug 修复通常可以直接提交 Pull Request。新功能、公共 API、数据格式、核心模型或跨仓库变更应先创建 Issue 或 Discussion。

- [贡献指南](https://github.com/matharts/.github/blob/main/CONTRIBUTING.md)
- [组织治理入口](https://github.com/matharts/.github/blob/main/GOVERNANCE.md)
- [开放式讨论](https://github.com/orgs/matharts/discussions)
- [社区行为准则](https://github.com/matharts/.github/blob/main/CODE_OF_CONDUCT.md)

## 支持与安全

- 一般使用问题、功能建议和讨论入口，请参阅[支持指南](https://github.com/matharts/.github/blob/main/SUPPORT.md)。
- 安全漏洞必须按照[安全策略](https://github.com/matharts/.github/blob/main/SECURITY.md)私密报告，不得公开提交漏洞细节。
